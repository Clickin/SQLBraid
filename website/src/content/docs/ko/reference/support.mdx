PV16 정확한 최종 revision 검증은 대기 중입니다. 이 페이지는 현재 SHA, CI,
배포 또는 Official 지원 주장을 의도적으로 하지 않습니다. 패키지 이름,
로컬 fixture 또는 계획된 workflow는 릴리스 증거가 아닙니다.

## 증거 label

- **Pending** — 구현 경로는 있지만 PV16 최종 릴리스 게이트 증거가 아직 제공되지 않았습니다.
- **Historical** — 정확한 revision 또는 과거 workflow가 조합을 실행했지만 현재 PV16 tree를 증명하지 않습니다.
- **Compatible expectation** — public API와 어댑터 계약에 기반한 기대이며 릴리스 게이트 주장이 아닙니다.
- **Custom** — 사용자가 제공한 `QueryExecutor` 또는 `ConnectionProvider`입니다.
- **Unsupported** — 필요한 SQLBraid capability가 의도적으로 없습니다.

## Capability 증거 매트릭스

Dialect, driver, runtime, server version은 별도 증거 축입니다. 계획 taxonomy는
[`docs/pv16-capability-evidence.json`](https://github.com/Clickin/SQLBraid/blob/main/docs/pv16-capability-evidence.json)에
기록하며 runtime은 이 파일을 읽지 않습니다. 이름이 지정된 exact-SHA 테스트가
실행될 때까지 모든 항목은 Pending입니다.

| Dialect / driver | Native DML-returning | Bulk mode | Stream 경계 |
| --- | --- | --- | --- |
| PostgreSQL / `pg` | `RETURNING` | `prepared-loop` | optional `pg-cursor` |
| MySQL / `mysql2` | 일반 DML `RETURNING` 없음 | `prepared-loop` | prepared stream; drain 또는 discard |
| MariaDB / Connector | 문서화된 `INSERT`, `DELETE`, `REPLACE ... RETURNING` | `connection.batch()`의 `native-bulk` | connector stream; 정확한 form은 별도 테스트 |
| SQLite / `node:sqlite` | `RETURNING` | `prepared-loop` | `StatementSync.iterate()` |
| SQLite / `sqlite-wasm` | `RETURNING` | statement reset을 통한 `prepared-loop` | 하나의 direct browser resource |
| SQLite / Cloudflare D1 | binding이 row를 노출하는 `RETURNING` | 한 번의 `batch()`인 `remote-batch` | incremental cursor 없음: `BRAID_STREAM_UNSUPPORTED` |
| Oracle Thin | `RETURNING ... INTO` + `sql.out()` | `executeMany()`의 `native-bulk` | `ResultSet`을 lease 반환 전에 close |
| SQL Server / Tedious | `OUTPUT` | `prepared-loop` | bounded Request event; 완료 후 release |

PV16의 DML-returning은 `sql.rows`와 materialized `db.execute`, `db.all`,
`db.one`, `db.maybeOne`만 지원 범위로 문서화합니다. SQLite RETURNING은
출력을 먼저 축적하고 SQL Server OUTPUT은 이후 실패 전에 행을 보낼 수 있으므로
`db.stream()`을 cross-driver 약속으로 만들지 않습니다.

`db.bulk(inputs, factory)`는 command-only, 하나의 shape × N values, 하나의
physical lease, 하나의 observer 작업입니다. 빈 입력은 acquire하지 않습니다.
Root bulk에는 portable transaction/auto-chunking 약속이 없고 driver는
`native-bulk`, `pipeline`, `prepared-loop`, `remote-batch` 중 실제 모드를
보고합니다.

첫 번째 파티 행 스트리밍 primitive는 dialect flag가 아닌 서로 다른
드라이버 capability입니다.

| 어댑터 | `db.stream()` primitive | 중요 경계 |
| --- | --- | --- |
| PostgreSQL / `pg` | `pg-cursor` | Optional peer이며 capability가 없으면 `BRAID_STREAM_UNSUPPORTED`입니다. |
| MySQL / `mysql2` | raw prepared `Execute.stream()` | prepared/binary 실행을 유지하고 lease 반환 전에 drain 또는 discard합니다. |
| MariaDB / Connector/Node.js | connector stream | `mysql2`에서 상속되지 않는 MariaDB driver capability입니다. |
| SQLite / `node:sqlite` | `StatementSync.iterate()` | native iterator 종료가 정리 경계입니다. |
| SQLite / `sqlite-wasm` | OO1 step/pull | 하나의 direct browser resource이며 충돌하는 root 작업은 거부합니다. |
| SQLite / Cloudflare D1 | 없음 | `BRAID_STREAM_UNSUPPORTED`; streaming을 흉내 내기 위해 paginate하지 않습니다. |
| Oracle Thin | `ResultSet` | 모든 ResultSet을 닫고 close 실패 시 lease를 폐기합니다. |
| SQL Server / Tedious | Request row event + bounded queue | lease 반환 전에 request가 완료되어야 합니다. |

Materialized `db.all()`은 의도적으로 버퍼링합니다. `db.call()`은 이질적인
result-set schema를 매핑하기 전에 루틴 result 리소스를 materialize하고
닫습니다. PostgreSQL refcursor 호출에는 기존 transaction이 필요합니다.
MySQL prepared CALL OUT/INOUT은 mysql2 3.x에 검증된 public carrier
discriminator가 없어 거부합니다. SQLite 루틴 호출은 지원하지 않으며 SQL
Server `CURSOR VARYING OUTPUT`은 애플리케이션 cursor 채널이 아닙니다.

Vite/browser/cloud 통합 또는 RC 배포를 주장하지 않습니다. PV16 검증 후
Main이 Pending 항목을 최종 증거로 교체해야 합니다.
