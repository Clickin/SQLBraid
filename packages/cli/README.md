# @sqlbraid/cli

Command-line tools for checking SQLBraid projects, inspecting queries,
comparing metadata, and generating typed models.

```sh
npm install --save-dev @sqlbraid/cli
```

Run `npx sqlbraid check`, `inspect`, `drift`, or `codegen` with the relevant
project options. The CLI operates on supplied source and metadata; it does not
create database connections.

See the [SQLBraid documentation](https://clickin.github.io/SQLBraid/).
