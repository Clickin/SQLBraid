# @sqlbraid/core

Low-level TypeScript contracts for SQLBraid. Defines types for templates, rendered statements, and adapter capabilities.

```sh
npm install @sqlbraid/core
```

This package provides common types, errors, and statement/parameter utilities. It does not connect to databases or execute queries. Use this when authoring a new driver adapter or building a deep integration.

See the [SQLBraid documentation](https://clickin.github.io/SQLBraid/) for details.
