# @sqlbraid/core

Public SQLBraid types and interfaces for typed SQL, database execution, and Standard Schema results.

```sh
npm install @sqlbraid/core
```

```ts
import type { Database, RowQuery } from "@sqlbraid/core";
```

Use this package for shared type contracts when implementing adapters or integrations. See the [SQLBraid documentation](https://clickin.github.io/SQLBraid/).
