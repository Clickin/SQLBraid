# @sqlbraid/core

Low-level TypeScript interfaces for SQLBraid. This package defines the types for templates, rendered statements and adapter capabilities.

```sh
npm install @sqlbraid/core
```

This package gives common types, errors and utilities for statements and parameters. It does not connect to databases and does not execute queries. Use it to write a new driver adapter or a deep integration.

See the [SQLBraid documentation](https://clickin.github.io/SQLBraid/) for details.
