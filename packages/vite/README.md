# @sqlbraid/vite

A Vite plugin that lowers guarded SQLBraid SQL templates during the build.

```sh
pnpm add @sqlbraid/vite vite
pnpm add @sqlbraid/template
```

Add `sqlbraid()` to your list of Vite plugins. The plugin supports TypeScript and JavaScript. It keeps compiler diagnostics and source maps.

See the [Vite integration guide](https://clickin.github.io/SQLBraid/latest/getting-started/vite/) and the [SQLBraid documentation](https://clickin.github.io/SQLBraid/).
