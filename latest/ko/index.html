쿼리 빌더 없이 SQL을 직접 작성하는 데이터 접근 라이브러리입니다.

SQLBraid는 TypeScript의 태그드 템플릿 안에 SQL을 그대로 작성할 수 있게 해줍니다. 값은 바인딩 파라미터로 전달하며, MyBatis 스타일의 동적 조건문은 SQL 주석 안에 작성합니다. 각 쿼리는 결과 타입이나 검증 스키마를 선언합니다.

파라미터를 바꾸고 브라우저의 인메모리 SQLite 데이터베이스에서 아래 쿼리를 실행해 보세요.

파라미터

값을 비우면 해당 조건이 제거됩니다. 값은 SQL에 합쳐지지 않고 파라미터로 바인딩됩니다.

SQL · 읽기 전용

sql.rows`
  SELECT account_id, account_name, balance
  FROM finance_accounts
  /*@braid where*/
    /*@braid if ${currency !== ""} */
      AND currency = ${currency}
    /*@braid end*/
    /*@braid if ${minBalance !== null} */
      AND balance >= ${minBalance}
    /*@braid end*/
    /*@braid if ${search.trim().length > 0} */
      AND account_name LIKE ${`%${search.trim()}%`}
    /*@braid end*/
  /*@braid end*/
  ORDER BY balance DESC, account_id ASC;
`

파라미터를 바꾸고 쿼리를 실행해 보세요.
