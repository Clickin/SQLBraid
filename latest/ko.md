# SQLBraid

> TypeScript용 SQL 중심 데이터 접근 라이브러리.

SQLBraid는 TypeScript의 태그드 템플릿 안에 SQL을 그대로 작성할 수 있게 해줍니다. 값은 바인딩 파라미터로 전달하며, MyBatis 스타일의 동적 조건문은 SQL 주석 안에 작성합니다. 각 쿼리는 결과 타입이나 검증 스키마를 선언합니다.

## 직접 실행해 보기

파라미터를 바꾸고 브라우저의 인메모리 SQLite 데이터베이스에서 아래 쿼리를 실행해 보세요.

문서 사이트에서 렌더링된 [인터랙티브 미리보기](https://clickin.github.io/SQLBraid/latest/ko/interactive-preview/)를 사용할 수 있습니다.

[전체 인터랙티브 미리보기](/SQLBraid/latest/ko/interactive-preview.md)에서 SQL을 직접 수정하고 데이터베이스 스키마를 확인할 수 있습니다.
