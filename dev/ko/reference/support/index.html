런타임 및 드라이버 지원

PV16 구현 revision 2890ef65d15ac96a7e3471911b381340aa30579a는 아래의 세 workflow를 통과했습니다. 인증 범위는 매트릭스의 정확한 프로필과 capability 조건이며, 데이터베이스나 드라이버의 모든 버전이 아닙니다. CI 성공은 패키지 발행을 의미하지 않습니다.

증거 label

섹션 제목: “증거 label”
  • Official — 정확한 프로필에 무료 재현 환경과 릴리스 차단 real-engine 증거가 있습니다.
  • Conditional — 이름이 지정된 조건에서만 증거가 적용됩니다.
  • Pending — 해당 revision의 성공한 게이트가 아직 기록되지 않은 후보입니다.
  • Historical — 정확한 revision 또는 과거 workflow가 조합을 실행했지만 현재 PV16 tree를 증명하지 않습니다.
  • Compatible — 정확한 인증 대상이 없으며 더 넓은 host 또는 로컬 binding 검사는 통과할 수 있습니다.
  • Custom — 사용자가 제공한 QueryExecutor 또는 ConnectionProvider입니다.
  • Unsupported — 필요한 SQLBraid capability가 의도적으로 없습니다.

SQLBraid Capability 증거 매트릭스 (SQL 문법 지원 목록이 아님)

섹션 제목: “SQLBraid Capability 증거 매트릭스 (SQL 문법 지원 목록이 아님)”

Dialect, driver, runtime, server version은 별도 증거 축입니다. 검증된 taxonomy는 support/에 기록하며 runtime은 이 파일을 읽지 않습니다. 대화형 매트릭스는 CI가 검사하는 동일한 기계 판독 대상, capability 조건, test ID의 정식 표시입니다. 정확한 8개 프로필이 인증되었습니다. D1은 로컬 workerd binding을 통과했지만 managed SQLite 버전이 공개되지 않아 Compatible로 유지합니다.

PV16의 DML-returning은 sql.rows와 materialized db.execute, db.all, db.one, db.maybeOne만 지원 범위로 문서화합니다. SQLite RETURNING은 출력을 먼저 축적하고 SQL Server OUTPUT은 이후 실패 전에 행을 보낼 수 있으므로 db.stream()을 cross-driver 약속으로 만들지 않습니다.

db.bulk(inputs, factory)는 command-only, 하나의 shape × N values, 하나의 physical lease, 하나의 observer 작업입니다. 빈 입력은 acquire하지 않습니다. Root bulk에는 portable transaction/auto-chunking 약속이 없고 driver는 native-bulk, pipeline, prepared-loop, remote-batch 중 실제 모드를 보고합니다.

첫 번째 파티 행 스트리밍 primitive는 dialect flag가 아닌 서로 다른 드라이버 capability입니다.

어댑터 db.stream() primitive 중요 경계
PostgreSQL / pg pg-cursor Optional peer이며 capability가 없으면 BRAID_STREAM_UNSUPPORTED입니다.
MySQL / mysql2 raw prepared Execute.stream() prepared/binary 실행을 유지하고 lease 반환 전에 drain 또는 discard합니다.
MariaDB / Connector/Node.js connector stream mysql2에서 상속되지 않는 MariaDB driver capability입니다.
SQLite / node:sqlite StatementSync.iterate() native iterator 종료가 정리 경계입니다.
SQLite / sqlite-wasm OO1 step/pull 하나의 direct browser resource이며 충돌하는 root 작업은 거부합니다.
SQLite / Cloudflare D1 없음 BRAID_STREAM_UNSUPPORTED; streaming을 흉내 내기 위해 paginate하지 않습니다.
Oracle Thin ResultSet 모든 ResultSet을 닫고 close 실패 시 lease를 폐기합니다.
SQL Server / Tedious Request row event + bounded queue lease 반환 전에 request가 완료되어야 합니다.

Materialized db.all()은 의도적으로 버퍼링합니다. db.call()은 이질적인 result-set schema를 매핑하기 전에 루틴 result 리소스를 materialize하고 닫습니다. PostgreSQL refcursor 호출에는 기존 transaction이 필요합니다. MySQL prepared CALL OUT/INOUT은 mysql2 3.x에 검증된 public carrier discriminator가 없어 거부합니다. SQLite 루틴 호출은 지원하지 않으며 SQL Server CURSOR VARYING OUTPUT은 애플리케이션 cursor 채널이 아닙니다.
