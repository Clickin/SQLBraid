런타임 및 드라이버 지원

PV14 바인딩 전송과 observer 진단은 개발/리뷰 중입니다. 정확한 최종 revision의 검증이 대기 중입니다. 이 문서는 새 SHA, CI, 런타임 지원, 패키지 버전 또는 RC 배포를 주장하지 않으며, PV14 개발·리뷰·사용자 승인이 끝날 때까지 RC 배포는 연기됩니다. 아래 역사적 증거의 원래 provenance는 보존합니다.

지원 label의 의미는 다음과 같습니다.

  • Official — 해당 런타임/드라이버 조합이 SQLBraid 릴리스 게이트에서 실행되었습니다.
  • Compatible — 공개 API에서 동작할 것으로 예상되고 로컬에서 검사되었지만 릴리스 게이트 주장은 아닙니다.
  • Custom — 첫 번째 파티 어댑터가 아니라 QueryExecutor 또는 ConnectionProvider를 통해 연결됩니다.
  • Unsupported — 필요한 기능이 없거나 조합이 명시적 검사에 실패했습니다.

매트릭스는 증거이며 패키지가 존재한다는 사실로 추론한 약속이 아닙니다. 특히 실제 데이터베이스 검사가 릴리스 게이트에 포함되기 전까지 어댑터는 Official이 아닙니다.

Oracle은 node-oracledb Thin 모드를 대상으로 하며 Thick 모드는 Official이 아닙니다. SQL Server는 Tedious 어댑터를 대상으로 합니다. Oracle call() 경로와 SQL Server OUT/return-value 루틴 바인딩은 이 RC에서 Unsupported입니다. PostgreSQL, MySQL, SQLite는 파라미터 힌트를 조용히 무시하지 않고 명시적으로 거부합니다.

PV14 전송 맵 (검증 대기)

섹션 제목: “PV14 전송 맵 (검증 대기)”

다섯 first-party 어댑터는 동일한 논리 RenderedStatement를 받고 순수한 바인딩 설명 이후 각자의 요청을 구체화합니다.

경로 전송 유효 reuse 정책
PostgreSQL / pg text-positional $1..$N fresh unnamed simple, driver
MySQL / mysql2 text-positional ? driver reuse
SQLite / node:sqlite 문서화된 DatabaseSync.prepare(text)와 ? fresh simple, driver
Oracle Thin / node-oracledb descriptor를 사용하는 text-positional :1..:N driver cache reuse
SQL Server / Tedious TYPES.*를 사용하는 typed request @p1..@pN fresh Request/execSql, simple

요청한 reuse는 정책 입력이지 유효 reuse의 증거가 아닙니다. 유효 결과는 어댑터가 보고합니다. Placeholder 표기는 논리 prepared shape identity에 포함되지 않습니다.

Dialect, 드라이버, 실행 런타임, 트랜잭션 프로필은 서로 다른 축입니다. d4bc626의 성공한 PV13 runtime 게이트는 Linux x64의 Node 22.18.0에서 Oracle 23.9.0.25.07 Thin과 SQL Server 2022 CU18(16.0.4185.3)을 실행합니다. 로컬 SQL Server ARM 에뮬레이션은 Official ARM 지원 근거가 아닙니다. Bun/Deno 드라이버 서브패스와 Oracle Thick은 검증 범위가 아니며, 다섯 portable root는 고정 Node/Bun/Deno 버전에서 별도로 통과했습니다.
