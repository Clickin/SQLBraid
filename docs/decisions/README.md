# Architecture decisions

Architecture Decision Records (ADRs) record significant design choices, their context,
evidence, and consequences. Accepted decisions remain in history.
A later ADR can supersede an earlier decision without erasing its rationale.

Supporting experiments remain on dedicated evidence branches, not in the default
branch. Each ADR links to the exact evidence commit. Keep evidence branches unchanged;
use a separate branch for future experiments.
