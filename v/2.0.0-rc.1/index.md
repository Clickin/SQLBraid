# SQLBraid

> A SQL-first data-access library for TypeScript.

SQLBraid lets you write SQL inside TypeScript tagged templates. Values are passed as bound parameters, and MyBatis-style dynamic conditions live in SQL comments. Each query declares its result type or validation schema.

## Try it

Change the parameters and run the fixed query against an in-memory SQLite database in your browser.

The rendered [interactive preview](https://clickin.github.io/SQLBraid/v/2.0.0-rc.1/interactive-preview/) is available on the documentation site.

[Open the full interactive preview](/SQLBraid/v/2.0.0-rc.1/interactive-preview.md) to edit SQL and inspect the database schema.
