# 브라우저에서 바로 실행해 보기

> 브라우저 안의 임시 SQLite WASM 데이터베이스에서 실제 SQL을 고치고 실행해 봅니다.

아래 미리보기는 애플리케이션 번들에서 쓰는 것과 같은 SQLBraid SQLite WASM 어댑터를 사용합니다. SQL 문을 쓰거나 붙여 넣은 뒤, Web Worker 안의 공식 SQLite WASM `:memory:` 데이터베이스에서 실행해 보세요. 예제 데이터는 항상 같은 금융 데이터이며, 일부 계좌 이름은 한국어나 다른 유니코드 문자로 되어 있습니다.

이런 것을 해 볼 수 있습니다.

- 원하는 조건과 조인을 넣은 `SELECT` 문
- 임시 데이터베이스에 대한 `INSERT`, `UPDATE` 같은 단일 명령
- SQLite 문법·실행 오류를 확인하고 고친 쿼리 다시 실행하기
- **Inspect schema**로 예제 테이블 정의 보기
- 데이터를 바꾼 뒤 **Reset seeded database**로 원래 행 되돌리기

결과 표에는 처음 1,000행만 보여 줍니다. 탐색용 쿼리가 느려지지 않게 하기 위해서입니다. 워커가 10초 넘게 실행되면 미리보기가 워커를 새로 띄우고 데이터베이스를 초기화합니다.

여기서 실행하는 SQL은 이 임시 데이터베이스 안에서만 쓰는 원문 텍스트입니다. 일부러 이렇게 만들었습니다. 미리보기는 이 SQL을 서버 쿼리에 끼워 넣지 않고, 인젝션 안전성을 주장하지 않으며, 변경 내용을 저장하지 않습니다.

문서 사이트에서 렌더링된 [인터랙티브 미리보기](https://clickin.github.io/SQLBraid/v/1.0.2/ko/interactive-preview/)를 사용할 수 있습니다.

기본 경로에는 OPFS, 영구 저장소, `SharedArrayBuffer`, COOP/COEP 헤더가 필요 없습니다. 이것도 의도한 설계입니다. 실제 애플리케이션은 다른 SQLite WASM 저장 방식을 따로 고를 수 있습니다. 이 문서용 미리보기는 GitHub Pages 같은 정적 호스팅에서도 그대로 동작합니다.
