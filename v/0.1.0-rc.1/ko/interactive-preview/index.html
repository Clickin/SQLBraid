브라우저 인터랙티브 미리보기

아래 미리보기는 애플리케이션 번들과 같은 실행 경로를 사용합니다. 브라우저 워커가 SQLBraid SQLite WASM 어댑터를 가져오고, sql.rows(schema) 쿼리를 렌더링한 뒤 공식 SQLite WASM :memory: 데이터베이스에서 실행합니다. 한국어와 다른 유니코드 계좌 이름을 포함한 결정적 금융 fixture를 사용합니다.

다음 내용을 확인할 수 있습니다.

  • 지연 평가되는 @braid if 분기와 일반 값 바인딩
  • 렌더링된 SQLite SQL과 바인드 값
  • Standard Schema 검증 및 통화 표시 변환
  • WASM 데이터베이스에서 반환된 실제 표 형식 결과

Real SQLBraid + SQLite WASM

The query runs in a Web Worker against an in-memory SQLite database. There is no demo executor, persistence requirement, or server connection.

worker · :memory:

Ready to run.

TypeScript / SQL source

const accounts = sql.rows(financeSchema)`
  SELECT account_id AS accountId,
         account_name AS accountName,
         balance,
         currency,
         locale
  FROM finance_accounts
  /*@braid where*/
    /*@braid if ${koreanOnly}*/
      AND locale = ${"ko-KR"}
    /*@braid end*/
    /*@braid if ${minimumBalance > 0}*/
      AND balance >= ${minimumBalance}
    /*@braid end*/
  /*@braid end*/
  ORDER BY account_id
`;
